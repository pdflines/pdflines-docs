## 🔒 Privacy-first approach
PDFLines processes uploaded files on our servers only for the task you request.
Working uploads are deleted after processing. Generated outputs are kept for about one hour; signed download links expire after 15 minutes.
PDF to PowerPoint and PDF to Excel use Adobe PDF Services; we request deletion of those assets after the job.
Optional Google Analytics loads only with your consent and does not receive file contents, file names, or download URLs.

No sign-up required and no watermarks on outputs.
