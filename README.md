# PDFLines Documentation

This repository contains documentation, guides, examples, and public developer materials for **PDFLines** — a fast, secure, browser-based PDF toolkit.

## 🔗 Website
https://www.pdflines.com

## 📚 Contents
- How PDFLines works
- Privacy model (client-side vs server-side tasks)
- API examples (coming soon)
- Roadmap and planned tools
- Developer notes & FAQs

## 🔒 Privacy-first approach
PDFLines processes files either fully in the browser or deletes temporary files immediately after processing.  
No sign-up required, no watermarks, and no tracking.
